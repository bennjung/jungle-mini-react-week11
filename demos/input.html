비교군: 브라우저 기본 input (엔진 미사용)

엔진을 거치지 않는 순수 브라우저 input입니다. 같은 관찰 리스너를 붙여 커서·조합 동작의 기준선으로 비교합니다.

관찰 패널 (엔진 외부 · 관찰 전용)

엔진의 이벤트 prop이 아니라 앱 외부에서 input 요소에 직접 addEventListener로 붙인 리스너와 매 프레임 읽기로만 갱신합니다. 이 표시는 setState를 호출하지 않으므로 엔진 재렌더를 만들지 않습니다.

이벤트 로그 (최근 40개)

compositionstart / compositionupdate / compositionend / input과, input 직후 다음 프레임의 커서 점검을 기록합니다. 이 페이지는 composition 이벤트를 자동으로 dispatch하지 않습니다.

    실제 한글 IME 조합 입력은 사람이 직접 수행해야 검증됩니다. 자동으로 발생시킨 이벤트는 실제 IME 재현이 아닙니다.
