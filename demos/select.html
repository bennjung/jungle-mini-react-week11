기대 상태와 실제 SELECT DOM 비교

정상 조작 사례입니다. A가 선택된 상태에서 버튼 한 번으로 B 선택지를 추가하고 동시에 선택 상태를 B로 바꿉니다. 이 영역은 엔진 컨테이너 바깥에 있어 diff/patch 대상이 아니며, 값을 읽기만 합니다.

기대 상태 (useState 값)

state.selected - 선택되어야 하는 값
state.options - 화면에 있어야 하는 선택지
기대 selectedIndex - options.indexOf(selected)

실제 DOM (commit 후 읽기)

select.value - 실제 DOM 프로퍼티
select.selectedIndex - -1이면 선택 없음
선택된 option 값 - selectedOptions
select.options 값 - DOM에 실제로 존재하는 option value 목록
